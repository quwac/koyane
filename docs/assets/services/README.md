# Service icons

Icons in the root README are local assets displayed at 20 × 20 CSS pixels.
Monochrome Vercel and OCI marks have light and dark variants selected by the README's `picture` elements.

## Sources

- AWS, Google Cloud, Azure, and OCI PNGs: [Diagrams at `5a9e8af2d4e4`](https://github.com/mingrammer/diagrams/tree/5a9e8af2d4e48ae2bbd002a4c0ca714d5b9219e1/resources), under the [MIT license](diagrams-LICENSE.txt).
- Cloudflare Workers, Vercel, and Supabase SVGs: [SVG Logos at `22f03ffc4a65`](https://github.com/gilbarbara/logos/tree/22f03ffc4a652309d1fea4ade70f46e9e1d6602c/logos), under [CC0 1.0](logos-LICENSE.txt).

Service names and marks belong to their respective owners.
The self-hosted row uses a generic server SVG under this repository's [MIT license](../../../LICENSE).
The Vercel dark variant uses the same path with a white fill.
